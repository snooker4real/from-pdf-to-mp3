# from-pdf-to-mp3

A script that transforms pdf to mp3 file for lazy guys like me

**Stack** : Python

## Démarrage

```bash
python3 -m venv .venv && source .venv/bin/activate   # environnement virtuel
pip install -r requirements.txt   # installer les dépendances
python3 main.py   # lancer
```

## Structure

```
entire_file.py
main.py
requirements.txt
```
